# King Faisal Research Paper Code Submission

This repository now contains only the final paper-related code files in the repository root.

Included code:

1. `efficientnetv2s_levit256_xgboost_explainable_ai.ipynb`
   EfficientNetV2-S + LeViT-256 + XGBoost
   Includes explainable AI code using SHAP.

2. `efficientnetv2s_swinbase_xgboost_optuna.ipynb`
   EfficientNetV2-S + Swin-Base + XGBoost
   Includes Optuna-based hyperparameter optimization workflow.

3. `xgboost_optimizer.py`
   Standalone XGBoost optimization script.

4. `launch_hpo.py`
   Hyperparameter optimization launcher script.

Removed from this repository:

- all folders used for drafts, documentation, metrics, and trial notebooks
- non-approved experimental model files

The repository is intentionally flat and contains only the approved code files.
